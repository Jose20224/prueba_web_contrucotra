# H&C Constructora con React y Vite

Necesita Node.js 20.19 o superior, o 22.12 o superior.

1. Abra una terminal en esta carpeta.
2. Ejecute `npm install`.
3. Ejecute `npm run dev` y abra la dirección indicada.
4. Para generar la versión de producción ejecute `npm run build`. Los archivos se generan en `dist`.
5. Para probar esa versión ejecute `npm run preview`.

La navegación y el pie son componentes React en `src/main.jsx`. Los contenidos existentes están en `src/pages.json` y las interacciones originales en `src/sitio.js`. Los estilos están en `src/estilo.css` y `src/motion.css`.
Los datos de contacto y las imágenes de referencia deben verificarse antes de publicar.
